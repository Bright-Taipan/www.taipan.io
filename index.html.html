How Taipan Field works

1. Sign in
Create an account with email + password, or continue with Google. Your files are tied to this account, not to one device or browser.
2. Add files
Tap the + button (or drag and drop) to upload games, apps, photos, videos, or documents. Each file uploads securely to your own private cloud storage.
3. Auto-sorted into categories
Files are automatically placed into Games, Apps, Photos, Videos, Documents, or Other based on their type — use the category chips to filter, or move a file manually anytime.
4. View or use a file right in the browser
Tap any file to open a preview — images, video, and audio play inline, PDFs open in an embedded viewer, and text files display directly. No need to download just to check a file.
5. Remembered on any device
Because files are stored under your account (not just your browser), signing in on a phone, tablet, or another computer shows the exact same library.
6. Search and manage
Use the search bar to find a file by name, and use the action sheet (tap a file) to download, move, or delete it at any time.
